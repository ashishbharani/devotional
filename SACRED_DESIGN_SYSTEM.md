# Shared sacred design system

## Audit / preservation boundary

The source contains 42 (not 43) canonical categories, 2,112 groups and 43,085
works. Category, deity/group, subsection and paginated metadata listings are
generated by `hooks/generate.py`. Existing native information pages, manuscript
library, search, A–Z, favourites, counter, Panchang/calendar/converter, feedback
and Ephemeris all pass through `theme/main.html`. There is no standalone hosted
original-language/translation work reader to redesign: existing native text,
work-title/YouTube links, library discovery and external reading destinations
remain intact. No fabricated READ interface or destination is introduced.

## Reusable layers

- `sacred-site.css` extends the existing `--abp-*` interface with shared
  sandalwood, parchment, maroon, gold and saffron tokens. It is loaded after the
  homepage stylesheet. Existing dark, high-contrast, focus, reduced-motion,
  tablet table-to-card, large-text and print behaviours remain in place.
- One compact introductory ornament, shared frame, heading hierarchy, header,
  navigation and footer apply everywhere. No extra h1 or decorative links.
- Catalogue pages retain their canonical category accent colors, classifications,
  CWIDs, metadata, play/favourite controls, jump anchors and page boundaries.
- Editorial pages use serif reading copy. Manuscripts receive book-edge frames.
  Search, directories and forms use restrained parchment panels. Astronomy uses
  solar motifs and maroon panels, not artwork behind results or inputs.
- Seven small local owner-supplied portraits are reused only for exact category-1
  canonical group-name matches (Ganesha, Shiva/Mahesh, Vishnu, Krishna, Durga,
  Saraswati, Navagraha), including their continuation pages. Other traditions are
  not relabelled or assigned an inferred deity. No new third-party artwork.
- Original decorative SVG symbols vary with the existing category's subject:
  manuscripts, temple, lamp, solar, pilgrimage, performance or lotus. A single
  compact shared template renders a single inline path per page, avoiding large
  repeated images or additional requests. No SVG `use[href]` is introduced:
  Material's instant-navigation link rewriter cannot assign its read-only href.
  These drawings are decorative and excluded from the accessibility tree.

## QA

`node scripts/test_sacred_site.mjs` checks the shared shell on every generated
HTML page, all 42 category directories and artwork paths; it exercises 18
representative routes (including the 404 page) across desktop, tablet and Android-style mobile/touch
viewports, light/dark modes, images, one h1, large text/high contrast containment
and runtime errors. Screenshots are in `work/sacred-site` and uploaded by PR CI.
All 42 category landing pages are also visited at 320px and 1440px to check
their actual shared layout, main heading and horizontal containment.
Existing full search, navigation, native information-page contrast/focus,
Panchang/location and numerical Ephemeris suites remain mandatory.

This is a reviewable visual extension, not a direct production publish.
Screenshots/emulated touch are not physical Android or assistive-technology
certification. PDFs, source archives and canonical data must remain unchanged.
