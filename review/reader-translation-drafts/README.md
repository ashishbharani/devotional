# Original book translation drafts — unpublished

The owner authorized creating original Hindi and English translations from the
ancient scriptures on 5 November 2026. These are authored from the committed
Sanskrit/Awadhi witnesses, not copied modern publisher translations.

`bhagavad-gita/chapter-1.json` contains all 47 source entries for chapter 1 in
both languages. Each entry pins the exact original passage hash. Interpretive
and witness issues are recorded separately from translation text. These drafts
have not received independent linguistic or scriptural review; they must never
be labelled reviewed or silently copied into production reviewed-pack storage.

This is an authoring checkpoint, **not a completed book or website translation**.
The remaining 17 Gita chapters, all other books, and wider site text remain
unfinished. Nothing in this directory is loaded by the production collector.

Run `python scripts/test_reader_translation_drafts.py` for source identity,
complete drafted-chapter coverage and unpublished separation checks. These
checks do not establish translation accuracy. Do not fabricate reviewer records
or change completion gates merely to pass them.
